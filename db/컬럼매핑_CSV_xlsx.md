# 원자료 컬럼 매핑: CSV(2014-2024) ↔ xlsx(2025/2026)

요구사항정의서 v1.0 5.3절·6.1절에서 지적한 "컬럼 체계 상이" 문제를 실제 데이터로 검증하고 통합 매핑을 정리한 문서. DB 스키마([schema.sql](../db/schema.sql)) 설계의 근거자료.

## 1. 학교 식별자 — 가장 중요한 차이

| | CSV(2014-2024) | xlsx(2025/2026) |
|---|---|---|
| 고유코드 | **없음** | `정보공시 학교코드` (예: `S090003424`) |
| 대체키 | `학교명` + `본분교명`(본교/분교) | `학교명` |

→ **CSV는 학교코드가 없어 xlsx와 연결하려면 학교명 텍스트 매칭이 필요하다.** 연천교육지원청 13개 초등학교로 직접 대조한 결과 전부 정확히 일치했으나(예: "백학초등학교"), 전국 단위로 확장하면 동명학교·개명 이력 때문에 매칭 오류 가능성이 있다. → `school.school_code`를 PK로 하되, CSV 적재분은 `school_code`가 없으므로 **적재 시점에 (학교명, 교육지원청, 학교급) 조합으로 xlsx 기준 school_code를 역매핑**하고, 매핑 실패 건은 `school_code_matched = false`로 표시해 별도 검수한다.

## 2. 학교급·연도

| | CSV | xlsx |
|---|---|---|
| 학교급 | `학제명` = 초등학교/중학교/**고등학교** | 파일이 초/중으로 이미 분리(학교급코드 02/03) |
| 연도 | `조사기준일`(YYYYMMDD, 매년 4/1 기준) → 연도만 추출 | 파일명의 연도(2025/2026), 컬럼상 별도 연도 필드 없음 |

- 고등학교 행은 요구사항정의서 2.3절에 따라 **로드 시 제외**(교육지원청 정보 부정확, 시군구 집계 불일치).
- `학교상태` 값: 기존(원)교 / 신설(원)교 / **폐(원)교** / **휴(원)교** — 폐교·휴교는 통계에서 제외하거나 상태 플래그로 보존할지 로드 시점에 결정 필요(현재는 보존 + 플래그 권장, 임의 삭제하지 않음).

## 3. 행정구역 명칭

| 개념 | CSV | xlsx |
|---|---|---|
| 시도 | `시도` | `시도교육청`(교육청명, "○○교육청" 접미 다름) |
| 교육지원청 | `교육지원청` | `교육지원청` (동일 명칭 체계로 확인됨) |
| 시군구 | `행정구` | `지역` |

교육지원청 명칭은 두 원본에서 표기가 일치함(연천 사례로 확인: "경기도연천교육지원청" 동일). 시도/시군구 필드명만 다를 뿐 값 체계는 호환.

## 4. 학급수·학생수

| 개념 | CSV 컬럼 | xlsx 컬럼 |
|---|---|---|
| 전체 학급수 | `학급수_전체` | `계`(학급수) |
| 전체 학생수 | `학생수 전체` | `계.1`(학생수) |
| 학급당 학생수 | (파생, 없음) | `계.2` — **파생값이므로 DB 미저장, 조회시 계산** |
| 학년별 학급수/학생수 | `학급수_N학년`/`학생수_N학년` (N=1~6, 중학교는 4~6이 항상 0) | `N학년`/`N학년.1` (초는 N=1~6, 중은 N=1~3만 존재) |
| 특수학급 | `특수학급수`(학급수만) | `특수학급`/`특수학급.1`/`특수학급.2`(학급수·학생수·학급당) |
| 순회학급 | 없음 | `순회학급`/`순회학급.1`/`순회학급.2` |
| 교원수 | `전체교원수` 외 직위별 세분 컬럼 다수(교장/교감/보직/특수교사 등) | `교사수`(총계만) |

→ CSV가 교원 직위별로 훨씬 상세하지만, xlsx(최신연도)는 총계만 제공. 요구사항정의서 5.3절 "최신연도 학급당 학생수·학급수·교사수·특수학급 현황"은 xlsx의 총계 수준으로 충분하며, **10년 추이(CSV)는 총계·학년별까지만 통합 스키마에 반영**하고 교원 직위별 세부는 1차 MVP 범위 밖으로 둔다(필요 시 원본 CSV 재조회로 보완 가능하도록 원본 파일은 보존).

## 5. 통합 스키마 반영 방침

1. `school` 테이블: xlsx 기준 `school_code`를 표준 키로 채택(전국초중등학교위치표준데이터와도 동일 체계로 조인 가능할 것으로 예상 — ETL 시 검증 필요).
2. `school_year_stat` 테이블: CSV(2014-2024) + xlsx(2025, 2026) 세 원본을 세로로 통합, `source` 컬럼(`csv` / `xlsx`)으로 출처 구분해 향후 재검증 가능하게 함.
3. 고등학교 행 제외, 폐교/휴교는 `status` 컬럼으로 보존.
4. CSV의 교원 직위별 세부 컬럼은 이번 통합 스키마에 포함하지 않음(별도 필요 시 원본 CSV 직접 조회).

※ 이 문서는 연천교육지원청 실데이터로 검증했으며, 시범지역 확대 시(2차) 다른 교육지원청 데이터로 재검증이 필요하다.
